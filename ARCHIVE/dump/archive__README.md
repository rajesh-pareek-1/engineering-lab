# Archive

This folder holds legacy, duplicate, uncertain, or replaced material. Nothing was permanently deleted during the Interview OS migration.

## Subfolders

| Folder | Meaning |
| --- | --- |
| `legacy/` | Old READMEs, roadmaps, and duplicate source notes. |
| `repo-snapshots/` | Existing inventory/tree snapshots found before restructure. |
| `overwritten/` | Any file archived before regeneration during migration. |

Use active folders first. Open archive only when tracing history or recovering legacy wording.
