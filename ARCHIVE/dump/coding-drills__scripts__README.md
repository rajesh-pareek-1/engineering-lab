# Scripts Practice Area

Use this folder for fast coding practice without polluting the notes.

## Structure

- `csharp/` - C# scratch scripts and output-trap experiments.
- `javascript/` - JS callback, closure, and interview snippet practice.

## Rule

Keep scripts small and disposable. If a script becomes a reusable lesson, move the explanation into the parent `coding-drills/` notes.

## Suggested Practice Loop

1. Pick one question from `../csharp-output-traps.md` or `../csharp-coding-drills.md`.
2. Predict output before running.
3. Run the script.
4. Write the rule in one line.
5. Delete noisy experiments or keep only clean examples.
