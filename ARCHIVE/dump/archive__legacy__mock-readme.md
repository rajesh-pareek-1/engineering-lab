# Mock Interviews

Use these files as active drills, not reading material.

## How To Practice

1. Read only the question.
2. Speak your answer out loud.
3. Compare with the strong answer.
4. Rewrite your answer in one sharper version.
5. Repeat next day.

## Packs

- `backend-round.md` - backend API, security, queues, scaling.
- `dotnet-deep-dive.md` - C#, CLR, GC, OOP, SOLID.
- `sql-round.md` - SQL fundamentals and query problems.
- `resume-based-round.md` - project and resume defense.

## Rule

```text
Definition -> key insight -> project proof -> tradeoff
```
