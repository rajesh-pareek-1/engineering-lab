# Engineering Lab Interview OS

This repo is organized for fast backend interview revision with React Native and .NET specialization.

Start with [INDEX.md](INDEX.md). Use `revision/` for quick recall, `mock-arenas/` for spoken practice, `projects-explained/` for resume defense, and `engineering-lab/` only when you need deeper learning.

## Structure

| Folder | Purpose |
| --- | --- |
| `revision/` | Concise answer-ready summaries, edge cases, and common questions. |
| `mock-arenas/` | Mock interview packs with weak/expected/strong answer contrast. |
| `projects-explained/` | Resume-safe project stories, architecture, and tradeoffs. |
| `engineering-lab/` | Deep-dive/source notes and longer learning material. |
| `coding-drills/` | C#, SQL-to-EF, JavaScript, and scratch practice. |
| `resources/` | Resumes, referral templates, source map, and non-revision assets. |
| `archive/` | Legacy, duplicate, uncertain, or replaced material. Nothing was permanently deleted. |

## Revision Rule

Use the smallest useful file first:

1. `revision/last-minute-revision-path.md`
2. `revision/question-bank.md`
3. The relevant `revision/<topic>.md`
4. A mock pack from `mock-arenas/`
5. A deep-dive source from `engineering-lab/` only if recall is weak

Do not start interview week by opening deep-dive notes. Speak answers out loud, then use the deep-dive layer to repair gaps.
