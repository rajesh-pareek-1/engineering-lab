Edge Case Simulation

3 Scenarios
Upload Without Assignment

Driver opens the app before Trucker has assigned them. The Upload POD button must not appear. The shipment list shows empty or a "waiting for assignment" prompt.

⛔ Block: driver_id IS NULL on Shipment row
Regenerating Share Link

If Transporter generates a new share link, the old token is immediately invalidated. Any broker using the previous link will see an "Invalid Link" screen.

⚠ Old share_token overwritten · 30-day expiry resets
Expired Share Link Access

Broker opens a share link after 30 days. The public page shows "Link Expired" — no POD data is exposed. Transporter must generate a new link if needed.

ℹ Check: share_expiry < NOW() → show expired state
